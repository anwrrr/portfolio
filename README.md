# Mohamed Anwar — Portfolio

Static portfolio for Mohamed Anwar, a full-stack Angular and .NET developer.

## Site

This repository publishes through GitHub Pages from the root of the `main` branch. Open `index.html` locally or serve the directory with any static HTTP server to preview changes.

## Content notes

- The ERP case study describes a private client project without naming the client.
- `portrait.jpg` is Mohamed's public GitHub profile image.
- Project links lead to Mohamed's public GitHub repositories.

To update the site, edit the HTML and CSS files in this repository and push to `main`. GitHub Pages will publish the new version.
